Bundled EGM96 geoid data

Source: PROJ datum-grid egm96_15.gtx, distributed by Debian proj-data.
EGM96 was developed by US government agencies (NIMA/NASA).
PROJ distribution: https://proj.org/ and https://download.osgeo.org/proj/

The data has been resampled only in value precision (nearest centimetre);
the complete global 15-arc-minute grid is retained. Runtime interpolation
is bilinear. This is a geoid reference conversion, not terrain elevation.
