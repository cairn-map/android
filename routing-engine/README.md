# Vendored BRouter engine

Unmodified Java sources from BRouter tag **v1.7.9**, modules `brouter-core`, `brouter-mapaccess`, `brouter-expressions`, `brouter-codec`, and `brouter-util`.

Source: https://github.com/abrensch/brouter/tree/v1.7.9

Codeload archive SHA-256: `54e6b540597e0cfaca9aa6802f6ce67a9cf6de7f8a81d74061981f00f5506ecc`.

MIT licence and upstream copyright are retained in LICENSE and bundled in Cairn's assets. This module builds with Java 17 alongside the app; Android's build tools desugar supported language features. There are no external runtime library dependencies.

Application integration, bounded execution and graph preparation are documented in `../docs/ROUTING.md`. The profile and lookups under the application's routing assets come from the same upstream tag; `hiking.brf` is the unmodified upstream `hiking-mountain.brf`.
